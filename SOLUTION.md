## Full investigation and every new department

The optional area opens south of Records Stacks. Nothing below adds a permanent inventory or puzzle buff. The service lift is a physical shortcut unlocked anew each run.

1. Read the agenda and personnel file. In the stacks, read Ash's warning, WAIT for the local signal, then HIDE. This scene is action-triggered, not a real-time trap.
2. At IT, read the service ticket. Its requester is Scott, and the personnel file demonstrates that the record predates the present visit. CLOSE TICKET AS DUPLICATE opens the server room; read its console and maintenance order.
3. In Facilities, read the safety instructions and take the fuse. PULL LEVER to isolate the relay before inserting the fuse in the socket. SET DIAL TO RETURN, then RESET RELAY. The working service lift connects the executive elevator, Archives, and the new departments. Installing a fuse in a live socket is lethal and explicitly warned against.
4. Complete Legal/Procurement/HR and examine the children's drawings in Compliance. The agenda, file, drawings, and Investigations dossier are the four observations needed to COMPARE EVIDENCE. Remembered observations from an earlier run count as knowledge, not as carried equipment.
5. Enter the evidence room and take the revocation notice. Return to the IT server room and DISPUTE LEASE with the notice carried. The validated dispute opens the lift's Below access.
6. Read the return engine in Below. INSERT REVOCATION NOTICE INTO REVOCATION SLOT revokes the unsupported identity claim. The consent chair is not a shortcut; sitting before revocation is lethal. Complete the household-seal route and Asset Control afterward. The true ending acknowledges the investigation without becoming a separate ending.

## Recovery and deliberate hazards

At Asset Control, RECLAIM CANDLE retrieves a surrendered emergency candle before backtracking. The game stops an unlit return into the tunnel rather than killing you for a previously surrendered light. Other returned state assets can also be reclaimed there. Return them again before leaving.

Signing the Legal contract, attacking Jorge or a cat, selecting a wrong tarot card, deliberately entering the dark tunnel without a light, leaving with state property, servicing live equipment, and submitting to the unresolved consent chair can end the run. Hints, inspection, casebook reading, map reading, and unresolved parser clarification do not cause those actions.

An ambiguous noun produces a clarification. Reply with the exact name or displayed number, or CANCEL. A different command abandons the pending action. TAKE, GRAB, FETCH, and other taking aliases consistently refuse to pocket all three tarot cards; CHOOSE or SELECT commits the assessment.
